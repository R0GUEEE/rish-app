Rish นำบทสนทนากับเอเจนต์ เวิร์กสเปซ และการเรียกใช้เครื่องมือมาไว้บนโทรศัพท์ของคุณ
เลือกโมเดล อธิบายงานที่ต้องการ ตรวจสอบผลงาน และอนุมัติการเปลี่ยนแปลง
โดยไม่ต้องคอยเปิดคอมพิวเตอร์ทิ้งไว้ การเขียนโค้ดเป็นเพียงหนึ่งในการใช้งาน
ไม่ใช่วัตถุประสงค์เดียวของแอป

> **กำลังเตรียมพรีวิวซอร์สแบบทดลอง ยังไม่มีรีลีสเสถียรที่ติดตั้งได้**
> ขอบเขตของแพลตฟอร์มและสถานะการตรวจสอบบัญชี/การสมัครใช้งาน
> สรุปไว้ใน [แพลตฟอร์มและโมเดล](#แพลตฟอร์มและโมเดล)

¹ การลงชื่อเข้าใช้ด้วยการสมัครใช้งานตอนนี้รองรับเฉพาะ iOS เท่านั้น
BigModel Coding Lite ผ่านการตรวจสอบแล้ว ส่วน Codex และ Claude Code
ต้องใช้บิลด์ทดลองเสริมเลือกติดตั้ง ดูรายละเอียดการตรวจสอบได้ด้านล่าง

เลือก harness แล้วเชื่อมต่อด้วยคีย์ API หรือบัญชีที่บิลด์ของคุณรองรับ
จากนั้นเริ่มทำงานกับไฟล์และโปรเจกต์บนโทรศัพท์ของคุณ Rish จัดการ
วงจรเอเจนต์ เวิร์กสเปซ การอนุมัติเครื่องมือ และบันทึกการทำงาน
ส่วนอะแดปเตอร์ในตัวเชื่อมต่อไปยังบริการโมเดล

**การตรวจสอบบัญชีและการสมัครใช้งาน (iOS)**

- **Codex**: บิลด์ทดลองเสริมเลือกติดตั้งได้ตรวจสอบแล้วว่ารองรับการเข้าสู่ระบบ
  ด้วยอุปกรณ์ผ่าน CLI ทางการ การสนทนาข้อความผ่านการสมัครใช้งาน `gpt-5.6-luna`
  การเรียกใช้เครื่องมือ `list_dir` บนเครื่อง และการคงข้อมูลไว้หลังรีสตาร์ท
  CLI ทางการใช้เฉพาะการเข้าสู่ระบบเท่านั้น ยังไม่ได้ตรวจสอบเครื่องมือและโมเดลทุกตัว
- **GLM**: [ZCode](https://zcode.z.ai/en/docs/agents) คือผลิตภัณฑ์เอเจนต์ของ Zhipu
  ส่วน GLM คือตระกูลโมเดล การลงชื่อเข้าใช้ BigModel การคงข้อมูลหลังรีสตาร์ท
  และการตอบกลับของ Coding Lite GLM-5.3 ผ่านการตรวจสอบแล้ว แต่โควตาทดลองใช้ยังไม่ผ่าน
  และยังไม่ได้ผสานรันไทม์ ZCode ทางการเข้ามา
- **Claude Code**: บิลด์ทดลองเสริมเลือกติดตั้งบน iOS ได้ตรวจสอบแล้วว่ารองรับ
  การเข้าสู่ระบบด้วยการสมัครใช้งาน การตอบกลับข้อความด้วย Haiku 4.5
  ผ่าน CLI ทางการที่ไม่ถูกดัดแปลง และการคงข้อมูลไว้หลังรีสตาร์ท
  เส้นทางนี้ตอนนี้รองรับเฉพาะข้อความ โดยไม่มีเครื่องมือหรือไฟล์แนบ
  การวัดจริงหนึ่งรอบใช้เวลาประมาณ 4.5 นาที ประสิทธิภาพยังต้องพัฒนาต่อ

## ลงมือใช้งาน

| งาน | จุดเริ่มต้นแนะนำ |
| --- | --- |
| ทำงานกับข้อมูล | นำเข้าข้อความหรือไฟล์ PDF ขอให้สรุปประเด็นสำคัญ แล้วตรวจสอบโน้ตที่เอเจนต์บันทึกไว้ |
| จัดระเบียบไฟล์ | สำรวจไดเรกทอรีของโปรเจกต์ อ่านไฟล์ที่เลือก และอนุมัติเนื้อหาใหม่หรือเนื้อหาที่อัปเดต |
| ดูแลรักษาโปรเจกต์ | ตรวจสอบ Git status และ diff แก้ไขไฟล์ และอนุมัติ commit |

ตัวอย่างเหล่านี้ใช้ความสามารถของ iOS ที่พร้อมใช้งานในปัจจุบัน
เครื่องมือและรูปแบบไฟล์ที่รองรับแตกต่างกันตามแพลตฟอร์ม
สำหรับการทดลอง Linux Guest ดูที่
[เอกสารอ้างอิงรันไทม์](docs/development.md#honest-runtime-boundary)

## การทำงานบนเครื่องเกิดขึ้นอย่างไร

```text
Your task → Rish assembles context → Your chosen model service
                                           ↓ Text / tool requests
Phone workspace ← Local tools ← Rish validation and approval
```

เครื่องมือที่รองรับทำงานในสภาพแวดล้อมของแอปบนโทรศัพท์
คำขอต่อโมเดลจะส่งบริบทบทสนทนาและงานที่เลือกไปยังบริการที่คุณกำหนดค่าไว้:
**การทำงานบนเครื่องไม่ได้หมายถึงการอนุมานโมเดลแบบออฟไลน์**

Rish ผสานการทำงานกับไฟล์/Git แบบเนทีฟ รันไทม์ของ Rish
และ Linux Guest แบบทดลอง โดยไม่รับประกันความเข้ากันได้กับโปรแกรม
เดสก์ท็อปโดยสมบูรณ์ และการทำงานเบื้องหลังโดยไม่จำกัดเวลา
[คู่มือนักพัฒนา](docs/development.md) แยกความสามารถที่ตรวจสอบแล้ว
ออกจากเส้นทางทดลอง

| แพลตฟอร์ม | ขอบเขตปัจจุบัน |
| --- | --- |
| iOS / iPadOS | บทสนทนาแบบเนทีฟ, ไฟล์แนบ, แอป Files, Git และเครื่องมือเอเจนต์ที่ควบคุมได้ รวมถึงเลย์เอาต์ iPad แบบปรับอัตโนมัติ |
| Android | แชทผ่าน API แบบเนทีฟ การจัดเก็บข้อมูลรับรอง การกู้คืนเซสชัน และการแจ้งเตือนงานแบบกำหนดขอบเขต การทำงานของเอเจนต์ ไฟล์ และ Git บนเครื่องยังไม่พร้อมใช้งาน |
| HarmonyOS | การทดสอบชั่วคราวผ่านคอนเทนเนอร์ความเข้ากันได้ของ Android ไม่ถือว่ารองรับ HarmonyOS แบบเนทีฟ |

| การเชื่อมต่อ | วิธีปัจจุบัน |
| --- | --- |
| DeepSeek / DSH | คีย์ API พร้อมแคตตาล็อกโมเดลที่แก้ไขได้ ความสามารถขึ้นอยู่กับโมเดลและแพลตฟอร์ม |
| GLM | คีย์ API พร้อมการเชื่อมต่อบัญชี BigModel/Z.ai เสริมที่เลือกได้ ดูสถานะด้านบน |
| Codex | อะแดปเตอร์ API โดยบิลด์ทดลองเสริมเลือกติดตั้งบน iOS เพิ่มการลงชื่อเข้าใช้ด้วยการสมัครใช้งาน — ดูสถานะด้านบน |
| Claude Code | อะแดปเตอร์ API พร้อมการกำหนดค่าบริการที่เข้ากันได้ การเรียกข้อความด้วยการสมัครใช้งานตรวจสอบแล้วในบิลด์ iOS เสริมเลือกติดตั้ง ตามขอบเขตและเวลาแฝงที่ระบุด้านบน |
| บริการกำหนดเอง | บน iOS ให้เลือก Messages, Responses หรือ Chat Completions แล้วกำหนดค่าการจับคู่โมเดล |

## ระบบนิเวศ

Rish เป็นส่วนหนึ่งของตระกูลเครื่องมือ local-first และ AI-native จาก **[ZSeven-W](https://github.com/ZSeven-W)** `rish` ทำหน้าที่บูต Linux guest ภายในแอปนี้ ส่วนโปรเจกต์อื่น ๆ นำแนวคิดเดียวกันนี้ไปใช้บนพื้นที่อื่น — เทอร์มินัล แคนวาสสำหรับออกแบบ และหน่วยความจำของเอเจนต์

## เริ่มต้นใช้งาน

สำหรับตอนนี้ต้องบิลด์จากซอร์ส ยังไม่มีไฟล์ดาวน์โหลดสำหรับผู้ใช้ปลายทางที่เสถียร
เมื่อมีซอร์สแล้ว ให้เริ่มที่ไดเรกทอรีรากของรีโพสิทอรี:

```sh
node scripts/verify-source-checkout.mjs
npm ci --prefix apps/mobile
```

**iOS:** การเตรียมแบบเนทีฟต้องใช้ Xcode, Rust และ SDK ในเวอร์ชันที่ตรึงไว้
อ่าน[ข้อกำหนดเบื้องต้น](docs/development.md#ios-build-prerequisites)ก่อน แล้วจึงรัน:

```sh
./scripts/prepare-rish-ios.sh
./scripts/prepare-libgit2-ios.sh
cd apps/mobile/ios
pod install
cd ../../..
npm run ios --prefix apps/mobile
```

**Android:** เมื่อตั้งค่าสภาพแวดล้อมพัฒนา Android เรียบร้อยแล้ว ให้รัน
`npm run android --prefix apps/mobile` คู่มือนักพัฒนายังกล่าวถึง
[APK ทดสอบแบบสแตนด์อะโลน](docs/development.md#install-and-run-the-react-native-app) อีกด้วย

เปิดแอป เลือกโมเดล แล้วเชื่อมต่อด้วยคีย์ API หรือบัญชีที่รองรับ
บน iOS ให้สร้างหรือเลือกโปรเจกต์ ตรวจสอบบริบทของโปรเจกต์ แล้วเริ่มงาน
การลงชื่อเข้าใช้ด้วยการสมัครใช้งานของ Codex และ Claude Code ต้องใช้บิลด์ทดลองเสริมเลือกติดตั้ง
(ดู[คู่มือนักพัฒนา](docs/development.md)) สำหรับ BigModel ให้ดู
[คู่มือบัญชี](docs/zcode-account-login.md) ข้อมูลรับรองถูกเก็บไว้ในที่จัดเก็บที่ปลอดภัยแบบเนทีฟ
