¹ सब्सक्रिप्शन साइन-इन फ़िलहाल केवल iOS पर उपलब्ध है। BigModel Coding Lite सत्यापित है; Codex और Claude Code के लिए वैकल्पिक प्रयोगात्मक बिल्ड चाहिए। सत्यापन विवरण नीचे देखें।

कोई हार्नेस चुनें और API कुंजी या आपके बिल्ड द्वारा समर्थित अकाउंट से कनेक्ट करें। फिर
अपने फ़ोन पर फ़ाइलों और प्रोजेक्टों के साथ काम शुरू करें। Rish एजेंट लूप, वर्कस्पेस,
टूल मंज़ूरियाँ और निष्पादन रिकॉर्ड संभालता है; बिल्ट-इन अडैप्टर मॉडल सेवाओं से कनेक्ट होते हैं।

**अकाउंट और सब्सक्रिप्शन सत्यापन (iOS)**

- **Codex**: वैकल्पिक प्रयोगात्मक बिल्ड में ऑफ़िशियल CLI डिवाइस लॉगिन, सब्सक्रिप्शन
  `gpt-5.6-luna` टेक्स्ट चैट, लोकल `list_dir` टूल कॉल, और रीस्टार्ट के बाद भी बने रहना
  सत्यापित है। ऑफ़िशियल CLI केवल लॉगिन के लिए उपयोग होता है; सभी टूल और मॉडल सत्यापित नहीं हैं।
- **GLM**: [ZCode](https://zcode.z.ai/en/docs/agents) Zhipu का एजेंट उत्पाद है;
  GLM मॉडल परिवार है। BigModel साइन-इन, रीस्टार्ट के बाद बने रहना और Coding Lite GLM-5.3
  प्रतिक्रिया सत्यापित हैं; ट्रायल भत्ता सत्यापित नहीं है। ऑफ़िशियल ZCode रनटाइम एकीकृत नहीं है।
- **Claude Code**: वैकल्पिक iOS प्रयोगात्मक बिल्ड में सब्सक्रिप्शन लॉगिन, बिना बदले ऑफ़िशियल CLI
  से Haiku 4.5 टेक्स्ट प्रतिक्रिया, और रीस्टार्ट के बाद बने रहना सत्यापित है।
  यह रास्ता फ़िलहाल केवल टेक्स्ट को समर्थन देता है, टूल या अटैचमेंट के बिना।
  मापे गए एक टर्न में लगभग 4.5 मिनट लगे; प्रदर्शन में अभी सुधार बाक़ी है।

</td>
<td width="50%">

बिल्ट-इन DSH, Claude Code, Codex और GLM प्रविष्टियों से शुरू करें, या कोई संगत API

</td>
</tr>

## इसे काम पर लगाएँ

| कार्य | एक शुरुआती बिंदु |
| --- | --- |
| जानकारी के साथ काम | टेक्स्ट या PDF इंपोर्ट करें, मुख्य बिंदु पूछें, फिर वे नोट्स देखें जो एजेंट सहेजता है। |
| फ़ाइलें व्यवस्थित करें | प्रोजेक्ट डायरेक्टरी की जाँच करें, चुनी हुई फ़ाइलें पढ़ें, और नई या अपडेट की गई सामग्री को मंज़ूरी दें। |
| प्रोजेक्ट की देखभाल | Git स्थिति और diffs की समीक्षा करें, फ़ाइलें संपादित करें, और कमिट को मंज़ूरी दें। |

ये उदाहरण फ़िलहाल उपलब्ध iOS क्षमताओं का उपयोग करते हैं। समर्थित टूल और फ़ाइल
फ़ॉर्मैट प्लेटफ़ॉर्म के अनुसार बदलते हैं। Linux Guest प्रयोगों के लिए
[रनटाइम संदर्भ](docs/development.md#honest-runtime-boundary) देखें।

## लोकल निष्पादन कैसे काम करता है

```text
Your task → Rish assembles context → Your chosen model service
                                           ↓ Text / tool requests
Phone workspace ← Local tools ← Rish validation and approval
```

समर्थित टूल फ़ोन के ऐप-स्वामित्व वाले वातावरण में निष्पादित होते हैं। मॉडल अनुरोध
चुनी हुई बातचीत और कार्य संदर्भ आपकी कॉन्फ़िगर की गई सेवा को भेजते हैं:
**लोकल निष्पादन का मतलब ऑफ़लाइन मॉडल अनुमान नहीं है**।

Rish नेटिव फ़ाइल/Git संक्रियाओं, Rish रनटाइम और एक प्रयोगात्मक Linux Guest को जोड़ता है।
पूर्ण डेस्कटॉप-प्रोग्राम संगतता और अनिश्चितकालीन बैकग्राउंड निष्पादन का वादा नहीं है।
[डेवलपर गाइड](docs/development.md) सत्यापित क्षमताओं को प्रयोगात्मक रास्तों से अलग करके बताता है।

## इकोसिस्टम

Rish **[ZSeven-W](https://github.com/ZSeven-W)** के लोकल-प्रथम, AI-नेटिव टूल्स के परिवार का हिस्सा है। `rish` इस ऐप के भीतर Linux गेस्ट को बूट करता है; बाक़ी यही विचार दूसरी सतहों पर ले जाते हैं — टर्मिनल, डिज़ाइन कैनवास और एक एजेंट की मेमोरी।

| प्रोजेक्ट | यह क्या है |
| ------- | ---------- |
| **[rish](https://github.com/ZSeven-W/rish)** | फ़ोन पर असली Docker: शुद्ध Rust में लिखा no-JIT x86-64 फुल-सिस्टम इंटरप्रेटर, जो Linux बूट करता है और iOS तथा Android पर कंटेनर चलाता है। इस ऐप का Linux Guest यहीं से आया है। |

## शुरू करें

फ़िलहाल सोर्स से बिल्ड करें; कोई स्थिर एंड-यूज़र डाउनलोड नहीं है। सोर्स मिल जाने पर,
रिपॉज़िटरी रूट से शुरू करें:

```sh
node scripts/verify-source-checkout.mjs
npm ci --prefix apps/mobile
```

**iOS:** नेटिव तैयारी में पिन किए गए Xcode, Rust और SDK संस्करण चाहिए।
पहले [पूर्व-आवश्यकताएँ](docs/development.md#ios-build-prerequisites) पढ़ें, फिर चलाएँ:

```sh
./scripts/prepare-rish-ios.sh
./scripts/prepare-libgit2-ios.sh
cd apps/mobile/ios
pod install
cd ../../..
npm run ios --prefix apps/mobile
```

**Android:** Android डेवलपमेंट वातावरण कॉन्फ़िगर होने पर
`npm run android --prefix apps/mobile` चलाएँ। डेवलपर गाइड
[स्टैंडअलोन टेस्ट APK](docs/development.md#install-and-run-the-react-native-app) को भी समझाता है।

ऐप खोलें, मॉडल चुनें, और API कुंजी या किसी समर्थित अकाउंट से कनेक्ट करें।
iOS पर प्रोजेक्ट बनाएँ या चुनें, उसका संदर्भ देखें, और कोई कार्य शुरू करें। Codex और Claude Code
सब्सक्रिप्शन साइन-इन के लिए वैकल्पिक प्रयोगात्मक बिल्ड चाहिए ([डेवलपर गाइड](docs/development.md) देखें);
BigModel के लिए [अकाउंट गाइड](docs/zcode-account-login.md) देखें। क्रेडेंशियल
नेटिव सुरक्षित स्टोरेज में रहते हैं।
