# Rish brand

## Approved copy

> **Rish，你的随身 Agent。**
>
> 手机本地执行，模型自由接入。

For compact promotional placements:

> **随身 Agent，本地执行。**

Keep this wording consistent across the README, launch materials, and product
graphics. Rish serves multiple task types; do not narrow the brand to a coding
assistant. "Local execution" refers to the supported on-device runtime and
tools, while model requests go to the user's selected provider. Platform
availability and current limits belong in the accompanying description.

See [positioning and claim boundaries](../docs/positioning.md) for longer copy
and the evidence required for promotional demonstrations.

## Brand mark

The mobile mark is the original abstract geometry selected for the app. Its
lack of Harness-specific symbols lets it serve the Rish umbrella brand rather
than one DSH adapter:

- the folded ivory geometry is the app-owned local workspace and harness;
- the coral insert is the active command/output path;
- the final mark intentionally contains no whale or feature-specific symbol.

Color tokens:

- graphite `#08090B`
- warm ivory `#F4F1E9`
- signal coral `#FF6B3D`

Files:

- `rish-readme-icon.svg`: rounded README presentation of the launcher master;
  embeds the original PNG under a vector clip so GitHub needs no inline CSS.
- `dsh-app-icon-source.png`: selected AI concept source.
- `dsh-app-icon-1024.png`: normalized launcher master.
- `dsh-mark-transparent.png`: transparent, container-free launch-screen mark.

The selected concept was regenerated from the user-approved geometry with the
whale precisely removed. Launcher exports must not add plugin-specific or
feature-specific symbols.
